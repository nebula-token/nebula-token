# Code of Conduct

This project adheres to the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, assume good faith. Harassment and
personal attacks are not tolerated.

## Reporting

Report unacceptable behaviour to **hello@nebulatoken.dev**. Reports are read by
the lead maintainer ([`GOVERNANCE.md`](GOVERNANCE.md)).

You will get an acknowledgement within **72 hours**. Your report and your
identity stay confidential: they are not shared with the person reported, nor
with anyone else, without your agreement. You may ask for a report to be
recorded without any action being taken.

If the report concerns the lead maintainer, say so in the message. There is
currently one maintainer, so that is a real limitation rather than a
formality — in that case you may instead report to the
[Contributor Covenant's own guidance](https://www.contributor-covenant.org/faq/)
for escalation options, or raise it publicly if you judge that safer. When a
second maintainer exists this document will name an independent recipient.

## Scope and consequences

The Code applies everywhere this project operates: issues, pull requests,
discussions, commit messages, and any space where someone is representing the
project.

Enforcement follows the Contributor Covenant's four-step ladder — correction,
warning, temporary ban, permanent ban — chosen in proportion to the behaviour
and to whether it is repeated. The reasoning for any enforcement action is
communicated to the person concerned.
